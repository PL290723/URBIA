# URBIA v0.1.0-rc.1 (versión candidata)

Versión candidata del MVP para la Feria de Proyectos TecNM Celaya 2026. Congela el backend
(API Go, inferencia Python, PostgreSQL/PostGIS, Docker Compose) y el frontend PWA.

## Qué incluye

- **Reportes ciudadanos:** foto validada y sin EXIF, ubicación GPS o manual, descripción.
- **IA:** sugerencia de categoría con YOLO26 (`bache`, `basura`) por gRPC; el reporte se guarda
  aunque la IA falle, y la detección original se conserva al corregir la categoría.
- **Consulta:** mapa por área visible, mis reportes, detalle con historial; los reportes ajenos
  se ven con ubicación aproximada.
- **Administración:** cambio de estado con historial inmutable, prioridad explicable con factores,
  posibles duplicados cercanos, estadísticas y usuarios.
- **Seguridad:** JWT con roles, CORS con lista blanca, límites de cuerpo y de login, encabezados
  defensivos, secretos fuera del repositorio.
- **Despliegue:** Docker Compose (base, migraciones, API, inferencia en CPU; GPU opcional),
  red interna sin internet, volúmenes persistentes, scripts de respaldo y cuentas de demo.
- **Frontend:** PWA instalable (React + Vite) con mapa Leaflet y panel administrativo.
